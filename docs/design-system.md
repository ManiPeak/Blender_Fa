# Blender Farsi — Figma-ready design system

**Status:** specification only. No Figma file has been created and no Blender theme has yet been applied or tested. This document is the implementation brief for a future Figma file and the native Blender theme prototype.

## Principles

1. **Blender first.** Preserve the location, sizing, and behavior of every existing editor and workspace region. Treat the stock Blender theme as the geometry baseline.
2. **Quiet depth.** Use small luminance steps and crisp separators for hierarchy. Do not imitate large-area glass blur; Blender does not expose a safe, universal backdrop-blur control for editor surfaces.
3. **Readable for long sessions.** Text and active states must remain legible at normal, dim, and high-DPI display settings.
4. **Meaningful accents.** Reserve saturated colors for selection, focus, and actionable state, not decoration.
5. **Direction-neutral workflow.** Persian strings may read RTL; node graphs, numeric controls, keyboard shortcuts, paths, and spatial editors remain in their familiar orientation.

## Typography and icon guidance

- Use Blender's native UI font and sizing controls; do not bundle or silently replace system fonts in the prototype.
- Preserve Blender's standard compact label scale, hierarchy, and iconography. Avoid emoji, custom decorative glyphs, and text-based icons.
- Keep icon states aligned to native Blender themes and preserve familiar operator icons.
- Validate Persian shaping, Latin-script identifiers, digits, punctuation, and mixed labels at 100%, 150%, and 200% UI scale. Do not claim font shaping coverage until tested on Windows.

## Interaction states

| State | Treatment |
| --- | --- |
| Default | Neutral surface, primary text, restrained separators |
| Hover | One subtle surface step brighter; no glow |
| Focus | Visible accent boundary/selection using Blender-native focus state |
| Pressed | Accent-darkened engaged state; short native feedback only |
| Selected/active | Accent cue plus existing native active-state icon/text semantics |
| Disabled | Muted text and icon, retaining readable contrast |

No custom transitions or persistent animation are proposed.

## Language selector component

The selector is a compact top-level item named **Language / زبان** in Blender's current top application menu row. Its menu has two native operator rows: **فارسی** (`fa_IR`) and **English** (`en_US`). The current selection is indicated using Blender's native depress/selected presentation. It must neither add a permanent region nor relocate any stock menu. Test labels and menu width with high-DPI scaling, mixed-script text, and both font backends.

## Accessibility and acceptance

- Check WCAG contrast calculations as a screening tool, then inspect real UI at actual sizes; theme text/control requirements cannot be reduced to one static ratio.
- Ensure hover is not the only indication of action or selection.
- Test keyboard access and shortcuts; do not hijack existing accelerators.
- Capture original and modified screenshots at identical OS resolution, scale, startup file, and workspace. Compare editor-region boundaries and key anchor positions. Any moved region, clipped header, less legible text, or viewport obstruction fails acceptance.
- Record redraw/startup timing and inspect input responsiveness before approving any further styling.
